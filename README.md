# ระบบแบบฟอร์มสำรวจข้อมูล SHORE

แบบฟอร์ม "Self Service Shore" (ธีมขาว, รองรับมือถือ) + เซิร์ฟเวอร์ Python
ที่นำข้อมูลที่กรอกไป **เขียนลงไฟล์ Excel แม่แบบของแต่ละท่า (TERMINAL) แล้วส่งอีเมลแนบไฟล์ให้อัตโนมัติ**

มี 2 เวอร์ชัน:

| เวอร์ชัน | ที่อยู่ | เหมาะกับ | ข้อจำกัด |
|---|---|---|---|
| **Python (เต็ม)** | ราก repo — `python run.py` | ใช้งานจริง ส่งอีเมลแนบไฟล์ Excel อัตโนมัติ คงหน้าตาไฟล์ครบ | ต้องมี Python + Microsoft Excel + ตั้งค่า SMTP |
| **Static (เบราว์เซอร์ล้วน)** | โฟลเดอร์ `docs/` — เปิดผ่าน GitHub Pages | เปิดใช้ได้ทันทีจากลิงก์ ไม่ต้องติดตั้งอะไร | ไม่มีเซิร์ฟเวอร์ จึงแนบไฟล์ส่งอีเมลอัตโนมัติไม่ได้ — ดาวน์โหลดไฟล์ + เปิดร่างอีเมลให้ ต้องแนบไฟล์เอง, สี/เส้นขอบบางส่วนของไฟล์ผลลัพธ์หาย |

> **GitHub Pages:** เปิดใช้จาก branch `main` โฟลเดอร์ `/docs`
> เวอร์ชัน static ประมวลผลทั้งหมดในเบราว์เซอร์ (SheetJS จาก CDN) ไม่มีการส่งข้อมูลออกนอกเครื่อง
> (เดิมใช้ ExcelJS แต่พบว่าไฟล์ที่เขียนออกมาเปิดใน Microsoft Excel ไม่ได้ — ดูหัวข้อ "ปัญหาที่เคยพบ" ด้านล่าง)
> สร้าง/อัปเดตไฟล์ใน `docs/` ด้วย `python build_docs.py`

## วิธีใช้งาน (เริ่มเร็ว)

```bash
python run.py
```

`run.py` จะทำให้เองทั้งหมด:

1. ติดตั้งไลบรารีที่ขาด (`openpyxl`, `xlrd`, `pdfplumber`, `pywin32`)
2. แปลงไฟล์แม่แบบ `.xls` → `.xlsx` เก็บไว้ใน `build/templates/` (ใช้ Microsoft Excel บนเครื่องแปลง เพื่อรักษาหน้าตาเดิม)
3. เปิดเว็บที่ <http://127.0.0.1:8000> และเปิดเบราว์เซอร์ให้อัตโนมัติ

> ถ้าเปิดเบราว์เซอร์ไม่ขึ้น ให้พิมพ์ URL `http://127.0.0.1:8000` เอง
> หยุดเซิร์ฟเวอร์ด้วย `Ctrl + C`

ติดตั้งไลบรารีเองล่วงหน้าก็ได้:

```bash
pip install -r requirements.txt
```

## ตั้งค่าการส่งอีเมล (SMTP) — จำเป็นสำหรับเวอร์ชัน Python

ก่อนใช้งานจริง ต้องตั้งค่าบัญชีอีเมลที่จะใช้**ส่ง**ก่อน (ไม่ใช่บัญชีผู้รับ):

1. คัดลอกไฟล์ `smtp_config.example.json` เป็นชื่อ **`smtp_config.json`** (อยู่ที่รากโปรเจกต์)
   ไฟล์นี้จะไม่ถูก commit ขึ้น git (อยู่ใน `.gitignore` แล้ว) — ปลอดภัยต่อรหัสผ่าน
2. กรอกข้อมูลบัญชีที่จะใช้ส่ง เช่น ถ้าใช้ Gmail:

   ```json
   {
     "host": "smtp.gmail.com",
     "port": 587,
     "use_tls": true,
     "username": "youraccount@gmail.com",
     "password": "รหัสผ่านแอป (App Password) 16 หลัก",
     "from_addr": "youraccount@gmail.com",
     "from_name": "SHORE Self Service"
   }
   ```

   > Gmail ต้องใช้ **App Password** (ไม่ใช่รหัสผ่านล็อกอินปกติ) — เปิด 2-Step Verification ก่อน
   > แล้วสร้างที่ [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)
   > ถ้าใช้อีเมลบริษัท (`@heungaline.co.th`) ให้ขอค่า SMTP host/port/username/password จากผู้ดูแลระบบอีเมลของบริษัท

3. หรือจะตั้งค่าผ่าน**ตัวแปรแวดล้อม**แทนไฟล์ก็ได้ (มีความสำคัญเหนือไฟล์):
   `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`, `SMTP_FROM_NAME`, `SMTP_USE_TLS`

4. รัน `python run.py` แล้วลองกรอกฟอร์มส่งดูได้เลย — ถ้ายังตั้งค่าไม่ครบ หน้าเว็บจะมีข้อความเตือนสีแดง
   ใต้หัวข้อ และกด "ส่งข้อมูล" จะขึ้นข้อความ "ยังไม่ได้ตั้งค่าการส่งอีเมล..." (ไฟล์ Excel ยังถูกสร้างและ
   เก็บไว้ที่ `output/` ตามปกติ แค่ยังส่งอีเมลไม่ได้)

**เวอร์ชัน static (GitHub Pages)** ไม่มีเซิร์ฟเวอร์จึงส่งอีเมลแนบไฟล์อัตโนมัติแบบนี้ไม่ได้ — เมื่อกด
"ส่งข้อมูล" จะดาวน์โหลดไฟล์ไว้ให้ พร้อมเปิดโปรแกรมอีเมล (mailto:) ที่กรอกผู้รับ/หัวเรื่อง/เนื้อหาไว้ให้แล้ว
เหลือแค่**แนบไฟล์ที่ดาวน์โหลดไว้เองแล้วกด Send** ถ้าต้องการให้เวอร์ชัน Pages แนบไฟล์อัตโนมัติได้จริง
ต้องต่อบริการส่งอีเมลฝั่งเบราว์เซอร์ เช่น [EmailJS](https://www.emailjs.com) ซึ่งแผนฟรีไม่รองรับไฟล์แนบ
(ต้องใช้แผน Personal $9/เดือนขึ้นไปถึงจะแนบไฟล์ได้) — บอกได้ถ้าต้องการให้ช่วยต่อให้

## การจับคู่ข้อมูลลง Excel แต่ละท่า

ทุกไฟล์: ถ้ามีคอลัมน์ **LINE** จะเติม `HAL`, รัน **No.** อัตโนมัติเมื่อมีหลายตู้

| TERMINAL | ไฟล์ผลลัพธ์ | ชีต | Vessel / Voy. | ตารางตู้ (แถวเริ่ม) |
|---|---|---|---|---|
| LCMT / LCB1 · **A0** | `A0-SHORE.xlsx` | `Sheet1` | `E6` / `I6` | แถว 14 — No.`A` Container`C` Booking`D` Size`E` Type`F` POD`G` |
| ESCO · **B3** | `B3-SHORE.xlsx` | `CHORE CY` | `C11` / `H11` | แถว 17 — No.`A` Container`B` Type`C` Size`D` POD`E` Booking`J` |
| LCIT · **B5/C3** | `B5C3-SHORE.xlsx` | `Sheet1` | – | แถว 2 — No.`A` Booking`B` ท่า`C`(=`LCB B5/C3`) POD`D` Agent`E`(=`HEUNG-A`) Vessel+Voy`F` Container`G` Size`I` |
| TLT · **A2** | `A2-FORM A.xlsx` | `FORM A` | `B8` / `I8` | ตาราง *ADDITIONAL CONTAINER* แถว 12 — Item`L` Container`M` SZ`N` TY`O` VGM`Q` Agent`R` POD`S` Booking`T` |
| Hutchison HLT · **A3 (C1,C2)** | `A3C1C2-HUTCHISON.xlsx` | `HPT` | ในตาราง `G` / `H` | แถว 10 — Item`A` **LINE`B`=HAL** Shipper`C` Size`D` Type`E` Container`F` Vessel`G` Voy`H` POD`I` Booking`K` Seal`L` **Status`M`** **PAYMENT TAEM`U`=CREDIT** |

หมายเหตุ
- **SIZE** เช่น `20 GP` จะถูกแยกเป็นขนาด (`20`) + ชนิด (`GP`) ให้อัตโนมัติตามคอลัมน์ของแต่ละท่า
  (ยกเว้น B5/C3 คอลัมน์ *ขนาด* เขียนติดกันเป็น `20GP`)
- **STATUS F/E**: คอลัมน์ที่ชื่อ *STATUS F/E* (ท่า A3) เขียนเป็น `F` / `E`
- ท่า **B5/C3**: ระบบล้างข้อมูลตัวอย่างเดิมในชีต `Sheet1` ก่อนเขียน (คงบรรทัดข้อความท้ายตารางไว้)
  และ **ไม่แตะ** ชีต `DataImport` / `ColumnMapping`
- ถ้าไฟล์ผลลัพธ์เดิมเปิดค้างใน Excel อยู่ ระบบจะบันทึกเป็นชื่อใหม่ที่มีวันเวลาต่อท้าย

## ปัญหาที่เคยพบ (เวอร์ชัน static)

**ไฟล์ที่ดาวน์โหลดจาก GitHub Pages เปิดใน Excel ไม่ได้ (แจ้งว่าไฟล์เสีย):**
สาเหตุคือไลบรารี **ExcelJS** ที่ใช้ตอนแรก เขียนไฟล์ `.xlsx` จากแม่แบบชุดนี้ออกมาผิดรูปแบบ
(ยืนยันแล้วว่าแม้ไม่แก้ไขข้อมูลใด ๆ เลย แค่โหลดแล้วเขียนกลับ Excel ก็เปิดไม่ได้ทุกไฟล์ ทุกเวอร์ชันของ ExcelJS ที่ลองมา)
จึงเปลี่ยนไปใช้ **SheetJS (xlsx.full.min.js)** แทน — ทดสอบแล้วว่า Excel เปิดได้ปกติทุกท่า พร้อมข้อมูล/เซลล์ผสานถูกต้อง
(ต้องตัดความกว้างคอลัมน์ส่วนเกินทิ้งด้วย เพราะ SheetJS จะขยาย `<col>` ที่ตั้งความกว้างแบบเต็มช่วงคอลัมน์
ให้กลายเป็นรายการแยกเป็นหมื่นรายการ ทำให้ไฟล์บวมถึง ~1MB โดยไม่จำเป็น)

## โครงสร้างไฟล์

```
run.py                 เริ่มใช้งาน (ติดตั้ง lib + แปลงแม่แบบ + เปิดเว็บ)
server.py              เว็บเซิร์ฟเวอร์ (ไลบรารีมาตรฐาน ไม่ต้องใช้ Flask)
web/index.html         หน้าฟอร์ม (HTML/CSS/JS ในไฟล์เดียว)
lib/config_reader.py   อ่านตัวเลือกจาก Check.xlsx
lib/pdf_extract.py     pdfplumber ดึงข้อความ + วิเคราะห์ด้วยกฎ (ไม่ใช้ AI)
lib/xls_convert.py     แปลง .xls -> .xlsx (Excel COM หรือ xlrd)
lib/excel_fill.py      ตารางจับคู่ + เขียนข้อมูลลงแม่แบบ
lib/mailer.py           ส่งอีเมลแนบไฟล์ Excel ผ่าน SMTP
smtp_config.example.json  แม่แบบไฟล์ตั้งค่าอีเมล (ไม่มีรหัสผ่านจริง)
smtp_config.json       ไฟล์ตั้งค่าอีเมลจริง (คุณสร้างเอง - ไม่ถูก commit)
Check.xlsx             ไฟล์คำสั่งตัวเลือก
A0/B3/B5C3/A3C1C2 .xls, A2 .xlsx   ไฟล์แม่แบบ
pdf_in/                วางไฟล์ PDF ที่จะนำเข้า
build/templates/       แม่แบบ .xlsx ที่แปลงแล้ว (สร้างอัตโนมัติ)
output/                ไฟล์ผลลัพธ์
```

## ข้อกำหนดระบบ

- Python 3.9+ (ทดสอบบน 3.14)
- Windows + **Microsoft Excel** สำหรับแปลง `.xls` ให้คงหน้าตาเดิม
  ถ้าไม่มี Excel ระบบจะถอยไปใช้ `xlrd` แปลงแบบเก็บเฉพาะค่า (ไม่มีการจัดรูปแบบ)
  หรือจะเปิดไฟล์ `.xls` ทั้ง 4 ใน Excel แล้ว *Save As* เป็น `.xlsx` วางไว้ใน `build/templates/` เองก็ได้
